# Documentação histórica

Os documentos desta pasta foram preservados por contexto e rastreabilidade. Foram produzidos
em maio de 2026 e descrevem a implementação percebida naquele momento; seus checklists,
status e alegações de testes ou prontidão não são evidência verificável do estado atual.

Atualmente, o SAAL neste repositório é um protótipo frontend sem backend ou persistência
real. Para o estado vigente, consulte o [README principal](../../README.md), as
[especificações SDD](../../specs/README.md), o [diagnóstico atual](../diagnostics/README.md)
e o [plano de qualidade](../quality/QUALITY_PLAN.md).

| Documento | Conteúdo preservado |
|---|---|
| [`CHECKUP_REPORT.md`](CHECKUP_REPORT.md) | Relatório antigo de checkup do site. |
| [`VERIFICACAO_COMPLETA.md`](VERIFICACAO_COMPLETA.md) | Relatório antigo de verificação e testes alegados. |
| [`DOCUMENTACAO_PROJETO.md`](DOCUMENTACAO_PROJETO.md) | Descrição histórica do projeto e de funcionalidades. |
| [`REQUISITOS_FUNCIONAIS.md`](REQUISITOS_FUNCIONAIS.md) | Requisitos legados; não substituem as specs atuais. |

Não use as afirmações de “produção pronta”, persistência, testes completos ou autenticação
real desses arquivos para orientar uma implantação.
